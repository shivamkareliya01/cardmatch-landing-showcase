# CardMatch Landing Showcase

Build a single-page, fully responsive React/Tailwind landing page for the credit-card recommendation quiz brand CardMatch, following the supplied brief exactly: premium deep navy dark theme with restrained lime and lavender accents; hero, interactive selectable quiz options and Continue/mock result state, pain-point grid with tilted card visual, solution with sticky note, repeated CTAs, full footer, scroll reveal animations, CTA shimmer/interactions, and mobile-first polish including optional non-cluttering sticky CTA. Keep it clean and component-based; no backend needed.
