# CardMatch landing page

- Replace the blank home page with a single responsive CardMatch landing page.
- Create a premium deep-navy visual system with restrained lime and lavender accents, crisp typography, compact radii, and accessible contrast.
- Build the full page flow: branded header, immersive hero, interactive card-preference quiz, pain-point grid with tilted card artwork, solution section with sticky-note detail, repeated calls to action, and complete footer.

- Add route-specific title, description, Open Graph, and Twitter metadata.
